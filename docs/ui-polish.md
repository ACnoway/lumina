# 用户端 UI 优化（2026-10-22）

## 风格与范围

沿用浅暖灰页面背景、白色面板和蓝色主要操作。聊天、生图和公共导航统一使用圆角按钮、线性图标、44px 主要操作高度、灰色辅助说明及蓝色键盘焦点。公共样式位于前端 `globals.css` 的 `ui-*` 组件类，图标位于 `components/UiIcon.tsx`。

本轮调整前端展示和交互，不增加后端附件类型、接口或数据库迁移。附件菜单目前仅提供图片上传，后续文件能力可以扩展该入口。

## 操作约定

- 聊天：点击输入区左下角“＋（添加附件）”，再点“上传图片”。菜单说明格式、每张 5 MiB 和最多 4 张的限制；模型不支持、未选择模型、已达上限时显示具体原因。
- 选图后展示缩略图、MiB 大小及“已选 N/4 张”；图片在发送消息时上传。格式/大小/数量错误不会加入本次选择，也不会阻止已有合法图片或纯文本发送；可以关闭错误提示。
- 切换到不支持图片的模型时保留待发图片，并明确要求切换模型或移除图片。中文输入法组合输入的 Enter 不触发发送。
- 模型选择区显示“支持图片”或“仅文字”，区分加载中、无模型、加载失败，失败时提供“重新加载”。
- 手机和平板通过“对话记录”打开抽屉，可新建、切换、删除会话；删除按钮始终可见。抽屉使用原生模态 dialog 管理焦点，支持 Escape、点击遮罩关闭，切换到桌面宽度时关闭并恢复页面滚动。
- 生图：使用与聊天一致的附件卡片，提供“上传参考图／更换图片”、预览及“移除参考图”，显示格式、大小及模型限制。非法替换不会丢失原先合法的参考图，错误显示在卡片附近。

## 验证流程

本地不启动应用或测试环境。先提交并推送，再由 `ssh lch` 进入 `/root/lumina` 快进拉取，执行前端 lint、生产构建，并在隔离环境验证浏览器行为。使用已有隔离 E2E 回归图片上传和纯文字链路，不修改生产配置或重启生产服务。

浏览器验收重点：

- 桌面及 320/390/768px 宽度无水平溢出，长模型名、长文件名和长消息正常折行。
- “＋”菜单可用鼠标和键盘操作；Escape、点击外部和移出焦点可关闭。
- 图片增删、4 张上限、非法格式/空文件/超限及纠正后的继续发送。
- 支持图片／仅文字模型切换、无模型、加载失败后重试、实际发送中状态。
- 手机端抽屉的新建、切换、删除、焦点恢复及滚动恢复。
- 生图参考图的上传、更换、预览、移除和不支持模型提示。
- 聊天纯文字、图片及原有生图参考图接口回归。
